Laptop Lab - 3D laptop customizer and hardware simulator (phase 1)

Open index.html in a modern browser with an internet connection.
It loads three.js (r128) from cdnjs and the Archivo font from Google Fonts.

Included: homepage, interactive 3D laptop studio, part removal and replacement,
compatibility checks, saved builds (kept in memory for the session).
All specs and rules are simplified simulation data, not benchmark results.
